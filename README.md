# 🜏 ARCANUS 🜏

---

## ✨ 🔮 ¿Qué es Arcanus?

**ARCANUS** es un sistema de combate táctico basado en cartas de alineación mágica para **2 a 6 jugadores**.

Aquí no hay héroes…  
solo voluntades enfrentándose por el control de fuerzas que nadie debería tocar.

🜂 Asumes el rol de un **Arcano**  
🜄 Canalizas energía del universo  
🜁 Alteras el destino en cada turno  
🜃 Pagas el precio… siempre

---

## 🧠 🜏 Filosofía del juego

> ⚫ *El poder no se aprende… se invoca.*

Arcanus no es solo estrategia:  
es **intención contra intención**.

Cada carta:
- 🩸 Es una decisión irreversible  
- 🌀 Deforma el equilibrio del juego  
- ⚡ Puede cambiarlo todo en un instante  

> 🜏 *No gana el más fuerte… gana quien entiende el ritmo del caos.*
